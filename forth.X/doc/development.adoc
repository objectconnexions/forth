== System Development

=== Logging

`log_warn("LOG NAME", "log message at %Z", );`

Set up the default logging (on power up) in the `log_init()` function in `logger.c`.

.Flags

* `%S` - String
* `%I` - Unsigned 32 bit integer in decimal format
* `%X` - 2 digit hexadecimal number
* `%Y` - 4 digit hexadecimal number
* `%Z` - 8 digit hexadecimal number
